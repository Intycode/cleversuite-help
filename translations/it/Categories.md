# Categorie

Durante l’impostazione dei dati generali di un progetto, è possibile assegnarlo a una specifica categoria. Di default sono disponibili le categorie GENERALI e UL.

In questa sezione è possibile inserire tutte le categorie ritenute utili per la classificazione dei propri elementi. Il parametro CATEGORIA non influisce in alcun modo sulla definizione o sul calcolo dei parametri progettuali; esso viene utilizzato esclusivamente come criterio di filtro nella ricerca di elementi già progettati.

Qualora non si desideri classificare gli elementi, è sufficiente non modificare questa sezione. Nella schermata di impostazione dei dati generali verrà automaticamente assegnata la categoria GENERICO.
