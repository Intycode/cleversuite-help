# Categories

When setting up the general data for a design, you can assign it to a specific category. By default, the categories GENERAL and UL are available.

In this section, you can enter any categories you consider useful for classifying your elements. The CATEGORY parameter does not affect the definition or calculation of design parameters in any way; it is used only as a filter criterion when searching for elements that have already been designed.

If you do not wish to categorise the elements, simply leave this section unchanged. The GENERAL category will be automatically assigned on the general data settings screen.
